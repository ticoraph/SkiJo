# SkiJo

Skījō (スキー場) signifie « station de ski » en japonais.

Ce dépôt regroupe plusieurs projets de recherche et développement autour des stations de
ski.

## Projets

- [`resort_sizing`](resort_sizing/) : classification et prédiction de la taille des stations à
  partir d'un jeu de données public versionné.
- [`resort_slope_maps`](resort_slope_maps/) : extraction structurée des pistes, remontées,
  légendes et activités visibles sur des plans de pistes publics.
